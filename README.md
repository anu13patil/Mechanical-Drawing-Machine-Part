# 🔩 Flange – 3D Model & 2D Drawing

A circular **flange** with a central bore and four evenly spaced bolt holes, designed in **Autodesk Fusion**. The project includes a 3D model (STEP) and a dimensioned 2D engineering drawing (PDF and DWG).

---

View and rotate the interactive 3D model online in Autodesk Fusion:

---

## 📐 Project Overview

A flange is a flat, ring-shaped component used to connect pipes, shafts and other parts by bolting them together. This design is a simple circular flange with a centre hole and a bolt circle of four holes spaced 90° apart.

The 2D drawing includes the front view, side views and an isometric view, along with a title block.

---

## 📏 Specifications

All dimensions are in **millimetres (mm)**.

| Parameter | Value |
|-----------|-------|
| Outer diameter | Ø100 |
| Centre bore diameter | Ø40 |
| Bolt circle diameter (PCD) | Ø70 |
| Bolt hole diameter | Ø9 |
| Number of bolt holes | 4 |
| Bolt hole spacing | 90° |
| Thickness | 10 |

## 🚀 How to View

1. **Online:** click the Fusion link above, no installation required.
2. **3D model offline:** open `flange.step` in any CAD software, such as Fusion, FreeCAD (free), SolidWorks or Inventor.
3. **2D drawing:** open the PDF in any PDF viewer, or the DWG in AutoCAD, DWG TrueView or Autodesk Viewer.
